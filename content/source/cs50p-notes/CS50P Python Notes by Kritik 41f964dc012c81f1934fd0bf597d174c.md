## 🧭 How to use these notes

1. Read **Understand it first** to get the big idea in plain words.
2. Go through the **Notes**, and type the code yourself instead of copying it.
3. Check the **Key definitions** table.
4. Solve the **Programming questions** on paper or in your editor *before* opening the answer toggle.
5. Finish with the **MCQs** and the **Mini quiz**, then fix any you missed.

<aside>
💡

Tip: the toggles hide the answers. Always try first. Getting it wrong and then reading the answer teaches you more than just reading.

</aside>

## 🕹️ Play Python BlockQuest

Pick a lecture in the hotbar. Each level has a plain-language explanation, a waving pixel guide above the code, three questions from warm-up to tricky, and a coding mission with a full answer explanation. Correct answers pop with a chime; wrong answers shake with a lower sound. Use the sound button to mute or unmute. The final boss mixes ideas across the course, and progress is saved in this browser.

[cs50p-python-blockquest-v3.html](CS50P%20Python%20Notes%20by%20Kritik/cs50p-python-blockquest-v3.html)

## 🗺️ Learning path

| Lecture | Topic | You will be able to |
| --- | --- | --- |
| 0 | Functions and Variables | store data, talk to the user, write your own functions |
| 1 | Conditionals | make your program take decisions |
| 2 | Loops | repeat work, use lists and dictionaries |
| 3 | Exceptions | stop your program from crashing |
| 4 | Libraries | reuse code written by others |
| 5 | Unit Tests | prove your code works |
| 6 | File I/O | save and load data |
| 7 | Regular Expressions | match patterns in text |
| 8 | Object-Oriented Programming | build your own types with classes |
| 9 | Et Cetera | use sets, type hints, comprehensions, and generators |
