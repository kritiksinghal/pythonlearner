Track: Python from zero (about 50 lessons, in this order)
M1 Getting started: What is programming and Python; Your first program with print(); Variables and types; Numbers and math; Text (strings); Talking to the user with input() and f-strings
M2 Making decisions: True, False and comparisons; if, elif, else; and, or, not
M3 Repeating: while loops; for loops and range(); break, continue and loop else; Nested loops and patterns
M4 Collections: Lists; Indexing and slicing; Tuples; Dictionaries; Sets; Comprehensions; Sorting, zip and enumerate
M5 Functions: Defining functions; Parameters and return values; Scope; Default, keyword, *args and **kwargs; Lambda, map and filter; Recursion
M6 Errors, files, modules: Reading error messages; try and except; Reading and writing files; Modules and imports; A tour of the standard library; JSON and CSV
M7 Objects: Classes and objects; __init__ and methods; Inheritance; Special (dunder) methods; Dataclasses
M8 Advanced: Iterators and generators; Decorators; Context managers; Type hints; Testing your code (assert and unittest); Regular expressions; Virtual environments and pip; async and await basics
M9 Projects: Text adventure; To-do list with files; Quiz game; Bank account with classes; Expense tracker with JSON
Track: CS50P (10 lessons, one per CS50P week): Functions and variables; Conditionals; Loops; Exceptions; Libraries; Unit tests; File I/O; Regular expressions; Object-oriented programming; Et cetera
